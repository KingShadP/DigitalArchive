# Brand Governance

**KINGSHADP is the primary identity.**

## Approved permanent marks
1. KingShadP signature wordmark
2. KSP monogram
3. SP crest
4. Giragon
5. Halo-crown motif (only where explicitly appropriate)

## Never rules
- Never create KP initials.
- Never invent another crest.
- Never invent another mascot.
- Never redesign the Giragon.
- Never add generic king/royalty imagery.
- Never create fake luxury clichés.
- Never fabricate biography, achievements, or factual artist information.
- Never create uncontrolled alternate logos.

## Asset classes and boundaries

### Permanent brand assets
Core identity system that must remain stable across releases.

### Campaign art
Time-bound visuals for specific drops/releases; cannot replace permanent marks.

### Editorial art
Narrative storytelling visuals (archive/editorial context) that support, not redefine, identity.

### Experimental digital content
Interactive/temporary experiments (e.g., generative or WebGL modules) that remain isolated from core brand assets.

## Governance constraints
- Temporary campaign styling must never redefine permanent identity assets.
- Any new visual system proposal must explicitly map to one of the four asset classes.
- Brand consistency must survive layout variation (quiet, dense, cinematic, archival, interactive).
